# Image Assets Architecture — Pratiksha Maidpawar Portfolio

This directory structure organizes image assets for Pratiksha Maidpawar's portfolio.
Per Phase 1 requirements, screenshot slides are not used as final image backgrounds. Instead, individual cropped portraits, clean cutouts, and video covers will be slotted here.
